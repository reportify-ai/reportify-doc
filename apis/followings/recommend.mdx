## 说明

**URL**: `/v1/followings/recommend`
**方法**: `GET`  
**描述**: 推荐关注，根据指定的关注类型返回推荐的关注对象列表，并标记当前用户是否已关注。

### 请求参数
| 参数名      | 类型 | 必填 | 描述                                    |
|-------------|------|------|-----------------------------------------|
| follow_type | int  | 是   | 关注类型：`1` 公司，`2` 话题，`3` 渠道。     |

### 响应参数
| 参数名        | 类型   | 描述                             |
|---------------|--------|----------------------------------|
| items         | array  | 推荐关注列表。                   |
| &nbsp;&nbsp;follow_value  | str    | 关注对象的取值（如股票代码等）。   |
| &nbsp;&nbsp;name          | str    | 名称。                           |
| &nbsp;&nbsp;logo          | str    | 图标 URL。                       |
| &nbsp;&nbsp;is_following  | bool   | 当前用户是否已关注。             |
| &nbsp;&nbsp;group_key     | str    | 推荐分组标识。                   |
| &nbsp;&nbsp;description    | str    | 描述信息。                       |

### 请求示例

**cURL**
```bash
curl -X GET "https://api.reportify.cn/v1/followings/recommend?follow_type=1" \
-H "Authorization: Bearer YOUR_API_KEY"
```

**Python**
```python
import requests

url = "https://api.reportify.cn/v1/followings/recommend"
headers = {
    "Authorization": "Bearer YOUR_API_KEY"
}

params = {
    "follow_type": 1
}

response = requests.get(url, headers=headers, params=params)
print(response.json())
```
